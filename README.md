# Інтерактивні уроки — архів практичних завдань

Статичний сайт (HTML, CSS, JS без збірки) з інтерактивними практичними завданнями для учнів і вчителів.
Публікується через GitHub Pages з кореня репозиторію.

- **Каталог** (`index.html`) — усі завдання з фільтрами за папкою (предметом), тегами, рівнем складності, місцем виконання й пошуком.
  Фільтри зберігаються в адресі сторінки, тож відфільтрованим списком можна поділитися посиланням.
- **Завдання** — окремі сторінки. Кожне перевіряється прямо в браузері, а наприкінці учень бачить результат саме цього завдання.
- Прогрес не зберігається: після оновлення сторінки завдання починається спочатку. Якщо завдання не завершене, браузер перепитає перед закриттям вкладки чи переходом на іншу сторінку.

## Структура

```
index.html                    каталог
data/catalog.js               папки, теги й список завдань (єдине джерело для каталогу та заголовків сторінок)
assets/
  css/platform.css            базові стилі (кнопки, картки, модальні вікна)
  css/catalog.css             стилі каталогу
  css/task.css                стилі сторінки завдання та панелі результату
  js/catalog.js               фільтри й картки каталогу
  js/task-runtime.js          запуск завдання: контекст у пам’яті, підтвердження перед виходом, панель результату
  js/lesson-kit.js (+ css)    спільні помічники для ігор-завдань
lessons/
  adobe-illustrator/          папка предмета
    01-…html … 18-…html       сторінки завдань (від простішого до складнішого)
    engine/                   рушії завдань цієї папки + summaries.js (підсумок для панелі результату)
    icons/, img/              зображення
```

## Як додати завдання

1. Створіть сторінку в папці предмета, наприклад `lessons/<папка>/19-my-task.html`. Найпростіше скопіювати наявну сторінку з тим самим рушієм і змінити блок запуску:

   ```html
   <script src="../../data/catalog.js"></script>
   <script src="../../assets/js/task-runtime.js"></script>
   <!-- скрипти рушія завдання -->
   <script>
     TaskRuntime.start({ id: 'illustrator-19', game: 'ai-levels', data: { set: 'drills' }, wide: true });
   </script>
   ```

2. Додайте запис у `items` у `data/catalog.js` з тим самим `id`, папкою, номером `order`, тегами, рівнем і шляхом `file`.
   Заголовок, опис, теги й навігація «попереднє / наступне» на сторінці беруться з каталогу автоматично.

**Нова папка (предмет):** додайте запис у `folders` і створіть каталог `lessons/<id>/`. **Новий тег:** додайте його в `tags`.

### Контракт рушія завдання

Рушій реєструє `window.Games['<назва>'] = { mount(host, ctx) { … } }`. Середовище передає `ctx` з полями
`task.data`, `asset(path)`, `complete(score, details)`, `finish(score, details)`, `done(score)`, `toast(msg)`.
Виклик `ctx.finish(score, details)` завершує завдання: зникає підтвердження перед виходом і з’являється панель результату.
Додатковий підсумок для панелі можна описати функцією `TaskRuntime.summaries['<назва>'] = (details, ctx) => DOM-вузол`.

## Перегляд локально

```bash
python3 -m http.server 8000
```

Потім відкрийте http://localhost:8000/. Сторінки працюють і просто з диска (`file://`).

## Публікація на GitHub Pages

Settings → Pages → Build and deployment → **Deploy from a branch** → гілка `main`, папка `/ (root)`.
Файл `.nojekyll` вимикає обробку Jekyll, тож усі файли публікуються як є.
